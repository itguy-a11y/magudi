# Makudi

Website for Makudi, a digital marketing agency in Kochi, Kerala. Built with [Astro](https://astro.build).

## Run it

```
npm install
npm run dev       # local dev server
npm run build     # production build into dist/
npm run preview   # serve the production build
```

Needs Node 20 or newer.

## Where things live

- `src/data/site.js` – all page copy (services, hero steps, testimonials, contact details)
- `src/components/` – one component per page section
- `src/styles/global.css` – design tokens and all styles
- `src/scripts/` – hero animation (`hero-story.js`), scroll motion, menu and reveals
- `src/assets/` – logo files

The stats, testimonials, case studies, phone number, email and social links are sample content
from the design mockup. Replace them with real details before launch.
